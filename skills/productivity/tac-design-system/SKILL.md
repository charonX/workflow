# design-system

## 何时调用

- `/tac-bootstrap-workflow` 初始化项目时发现没有设计系统。
- `/tac-ux-explore` 开始 DESIGN 阶段时发现没有设计系统。
- 用户主动说"建立设计系统"、"/tac-design-system"时。

## 输入

- 项目现有设计资料（品牌色、字体、已有 UI 截图、竞品参考等）
- 用户的审美偏好（可选）
- PRD 中的用户画像和产品定位

## 输出

- `.aiassist/global/DESIGN.md`（设计系统文档）
- `.aiassist/global/tokens.css`（**可运行的 CSS 自定义属性**）
- 设计系统包含：
  - 色彩系统（含 hex 值 → CSS 变量）
  - 字体系统（含 font-family → CSS 变量）
  - 间距/圆角规范（含数值 → CSS 变量）
  - 阴影/边框规范（含数值 → CSS 变量）
  - 组件形态（按钮、卡片、输入框等 —— CSS 类或参考实现）
  - 情绪/调性描述

## 执行步骤

1. **检查现有设计资料**：
   - 是否存在 `.aiassist/global/DESIGN.md`？是否存在 `.aiassist/global/tokens.css`？
   - 是否存在 `.aiassist/global/STANDARDS.md`？
   - 项目 CLAUDE.md 是否有设计相关约定？
   - 是否有品牌指南、Figma 链接、参考截图？
2. **判断是否需要新建**：
   - 如果已有完整设计系统（`.aiassist/global/DESIGN.md` + `.aiassist/global/tokens.css`）→ 告知用户并退出。
   - 如果只有 `.aiassist/global/DESIGN.md` 无 `.aiassist/global/tokens.css` → 从 DESIGN.md 提取 token 生成 `.aiassist/global/tokens.css`。
   - 如果缺失或不全 → 进入建设流程。
3. **访谈用户**（如需要新建）：
   - 产品调性是什么？（专业/活泼/高端/亲和等）
   - 目标用户是谁？
   - 有没有必须遵守的品牌色/字体？
   - 有没有竞品或参考应用？
   - 平台优先级？（iOS/web/Android 等）
4. **生成设计系统文档**（`.aiassist/global/DESIGN.md`）：
   - 使用 markdown 格式。
   - 包含具体 token 值（hex 颜色、字体名、间距数值）。
   - 包含组件形态描述和示例。
5. **生成 CSS Token 文件**（`.aiassist/global/tokens.css`）：
   - 将所有设计 token 输出为 CSS 自定义属性。
   - 这是 `/tac-ux-explore` 生成 HTML 原型时的**绑定视觉约束**——原型必须 `<link>` 此文件，不发明系统外颜色或样式。

  --font-size-xs: 12px;

6. **保存到项目**：
   - `DESIGN.md` → `.aiassist/global/DESIGN.md`。
   - `tokens.css` → `.aiassist/global/tokens.css`。
7. **提示下一步**：设计系统已建立，可以开始 `/tac-ux-explore`。在 HTML 原型中通过 `<link rel="stylesheet" href="../../global/tokens.css">` 引用。

## 与 `/tac-ux-explore` 的关系

- `/tac-design-system` 是项目级、一次性的。
- `/tac-ux-explore` 基于 `/tac-design-system` 的输出，为每个 story 生成高保真 HTML。
- `tokens.css` 是 `/tac-ux-explore` 的**绑定视觉约束**——HTML 原型通过 `<link>` 引用，CSS 变量名即为 token 名。
- HTML 原型中不发明系统外颜色或样式；如需新 token，回 `/tac-design-system` 更新。

## 纪律

- 设计系统是**项目级资产**，不是某个 story 的产物。
- 不要在一个 story 里推翻整个设计系统；如需调整，应回到 `/tac-design-system` 或更新全局 STANDARDS。
- 具体 story 的 HTML 原型可以基于设计系统做局部变体，但不能脱离设计系统乱飞。
- `tokens.css` 和 `.aiassist/global/DESIGN.md` 必须保持一致——tokens.css 是 DESIGN.md 的可运行形式。
